Features

Everything you need
to run a safe field trip

One platform for real-time tracking, attendance, parent communication, and emergency response.

Live GPS Tracking

Track every student and bus in real time on an interactive map. Teachers and admins see everyone's location at a glance.

QR Code Attendance

Students scan a time-limited QR code at each stop. Attendance is recorded instantly — no paper lists, no manual counts.

Instant Parent Alerts

Parents receive push notifications when the bus departs, arrives, or if their child is flagged outside a geofence zone.

Per-Bus Group Chat

Every bus gets its own chat channel. Teachers coordinate with co-teachers, and students stay informed during the trip.

Geofence Alerts

Define a safe radius around each stop. If a student wanders out of bounds, the teacher is immediately notified with an alarm.

Admin Dashboard

School admins create and manage trips, assign teachers and buses, monitor live activity, and view full audit logs.

How It Works

Up and running in minutes

From trip creation to real-time monitoring — the whole workflow is built right in.

1

Admin Creates the Trip

Set the itinerary, stops, geofences, and assign teachers and students to each bus from the admin dashboard.

2

Teacher Starts & Tracks

On the day of the trip, the teacher taps Start, manages QR attendance at each stop, and monitors the live map.

3

Students Check In

At each stop, students scan the QR code displayed on the teacher's phone. No app setup needed beyond logging in.

4

Parents Stay Informed

Parents receive automatic push notifications at every milestone — departed, arrived, and safely back at school.
